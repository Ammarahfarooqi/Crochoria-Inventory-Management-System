A cute **pixel-themed Inventory Management System** built with **Python** and **Tkinter** for managing handmade crochet products through a simple and user-friendly graphical interface.

---

## 🌸 Overview

Crochoria Inventory Management System is a desktop application that helps small handmade businesses organize their inventory efficiently. It allows users to add, search, update, display, and delete products while automatically saving all inventory data using file handling.

---

## 👾 Features

✨ Product Management
- ➕ Add Products
- 👀 Display All Products
- 🔍 Search by Product ID
- 🧶 Search by Product Name
- ✏️ Update Product Price & Stock
- 🗑 Delete Products with Confirmation

✨ Inventory
- 💸 Inventory Summary
- 💾 Automatic Data Saving
- 📂 Automatic Data Loading

✨ User Interface
- 🎮 Pixel-Themed GUI
- ⌨️ Keyboard Navigation (Enter Key Support)
- 🌸 Beginner-Friendly Interface
- 🩷 Soft Pastel Color Palette
