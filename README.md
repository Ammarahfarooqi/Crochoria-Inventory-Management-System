## 🌸 Overview

**Crochoria Inventory Management System** is a desktop application designed to help a small handmade crochet business organize and manage its inventory.

The application provides a graphical interface for managing products, tracking stock, searching inventory, and viewing inventory summaries. Product data is stored persistently using a text file, allowing inventory information to remain available between sessions.

This project was built to practice **Object-Oriented Programming, GUI development, file handling, and modular Python project structure**.

---

## 👾 Features

### ✨ Product Management

- ➕ Add new products
- 👀 Display all products
- 🔍 Search products by ID
- 🧶 Search products by name
- ✏️ Update product price and stock
- 🗑️ Delete products with confirmation

### 📦 Inventory Management

- 💸 View inventory summary
- 📊 Track total products and stock
- 💾 Automatically save inventory data
- 📂 Automatically load saved inventory data

### 🎮 User Interface

- ✮ Pixel-themed graphical interface
- 🌸 Soft pastel color palette
- ⌨️ Keyboard navigation with Enter key support
- 🪟 Separate windows for different operations
- 🩷 Handmade/Crochet-inspired visual design
